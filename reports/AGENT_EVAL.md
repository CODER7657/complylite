# Case-note agent: checker results

Generated by `scripts/run_agent_eval.py` with `groq:openai/gpt-oss-120b` on the top-ranked holdout alerts of the simulated
dataset (`default`, two per day). **The trading data is simulated**; the language model is real.

Every note goes through the deterministic checker in `app/surveillance/agent/checker.py`: cited trade IDs
must exist and belong to the alert, every stated figure is recomputed in SQL, every number in the prose
must trace back to a tool result, and the conclusion may not exceed the evidence level computed in code.
A failed draft gets one retry with the checker's feedback; a second failure falls back to a templated note.
