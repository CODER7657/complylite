# Case-note agent on false alerts: checker results

Generated by `scripts/run_agent_eval.py --false-alerts` with `groq:openai/gpt-oss-120b` on the highest-ranked holdout
alerts of the simulated dataset (`default`) that are NOT manipulation in the simulator: the
model's false positives, hard negatives included. **The trading data is simulated**; the language model is
real. The question is whether the agent can say DISMISS or REVIEW_FURTHER instead of ESCALATE.

Every note goes through the deterministic checker in `app/surveillance/agent/checker.py`: cited trade IDs
must exist and belong to the alert, every stated figure is recomputed in SQL, every number in the prose
must trace back to a tool result, and the conclusion may not exceed the evidence level computed in code.
A failed draft gets one retry with the checker's feedback; a second failure falls back to a templated note.
