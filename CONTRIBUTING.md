# Contributing

- One issue, one branch, one pull request, with tests including failure paths.
- Paste the real test output in the pull request; UI changes need screenshots at 375 and 1280 px.
- Report only measured numbers in docs; if a change moves a number, update it.
- No secrets or real personal data. Security issues: see [SECURITY.md](SECURITY.md).

Setup and test commands are in the [README](README.md).
